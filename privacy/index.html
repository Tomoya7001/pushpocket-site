プライバシーポリシー（PushPocket）

最終更新：2026-10-19

1. 収集する情報

PushPocket は、利用者の個人情報・利用状況・端末情報を収集しません。 アカウント登録、広告、アクセス解析（トラッキング）、外部のクラッシュ収集サービスの仕組みはありません。 開発者（私たち）のサーバーに情報が送られることはありません。

2. 通信について

PushPocket は、アプリの機能のためにインターネット上のサーバーと通信しません。 ゲームやプログラムをインターネットからダウンロードすることもありません。アプリが使う通信は次の 2 つだけです。

  • 端末の中だけの通信：ゲームを動かすとき、アプリは端末の中だけで動くサーバー（127.0.0.1）を使って、 取り込んだゲームのファイルをアプリ内の表示部品に渡します。端末の外からは接続できません。
  • 同じ Wi-Fi 内の通信（「PC から転送」）：この画面を開いている間だけ、端末の Wi-Fi のアドレスで待ち受け、 利用者自身の PC のブラウザに転送用のページを表示して、ゲームファイルを受け取ります。
    • 接続には画面に表示される 6 桁のコードが必要です。間違ったコードが続くと一時的に受け付けを止めます。
    • Wi-Fi 以外（モバイル通信など）では待ち受けません。
    • 画面を閉じると受け付けを止め、受け取り途中のファイルを消します。30 分間やりとりがないときも自動で止めます。
    • このとき、iOS から「ローカルネットワーク」の利用許可を求められます。許可しない場合、この機能だけが使えません。
    • 受け取るのはゲームファイルだけで、利用者の情報を PC や他の場所へ送ることはありません。

利用者が取り込んだゲームは、ゲーム自体がインターネットと通信することがあります（ゲームを動かす表示部品は、ゲームの通信を止めていません）。 その通信はゲームの作り手の仕様によるもので、PushPocket はその通信で扱われるデータを収集も送信もしません。

3. 端末内に保存する情報

次の情報は利用者の端末の中だけに保存され、アプリが外部へ送ることはありません。

  • 取り込んだゲームのファイルとセーブデータ
  • ライブラリの情報（ゲームの名前、判定結果、利用者が付けた年齢区分など）
  • 設定（表示、操作、ゲームごとのボタン配置など）と、年齢確認で入力した生まれた年
  • 不具合調査用の記録：診断ログ、クラッシュ記録、ゲームごとの互換性の記録

これらはアプリを削除すると端末から消えます。

4. 利用者が自分で書き出す場合

次の 2 つは、利用者が操作して共有先を自分で選んだときにだけ端末の外に出ます。アプリが自動で送ることはありません。

  • 「ログを書き出す」（設定 > 診断ログ）：診断ログ、クラッシュ記録、計測レポート（ある場合）の写し。
  • 「互換性レポートを共有」（ゲームの詳細画面）：ゲームのフォルダ名、判定結果、そのゲームの互換性の記録、 アプリの版、端末の機種と OS の版。端末の名前は含みません。ゲームのファイル自体も含みません。

5. 子どものプライバシー

アプリは年齢確認のために生まれた年をたずねますが、その値は端末内だけに保存され、送信されません。

Privacy Policy (PushPocket)

Last updated: 2026-10-19. This English text is a translation; if it differs from the Japanese text above, the Japanese text prevails.

1. Information we collect

PushPocket does not collect personal information, usage data, or device information about its users. The app has no account registration, no advertising, no analytics (tracking), and no third-party crash reporting service. No information is sent to servers operated by the developer (us).

2. Network communication

PushPocket does not communicate with servers on the internet for any of its features. It does not download games or programs from the internet. The app uses only the following two kinds of communication.

  • Communication inside the device only: when running a game, the app uses a server that runs only inside the device (127.0.0.1) to pass the imported game's files to the app's display component. It cannot be reached from outside the device.
  • Communication within the same Wi-Fi network ("PC から転送", Transfer from PC): only while this screen is open, the app listens on the device's Wi-Fi address, shows a transfer page in the browser on the user's own PC, and receives game files.
    • Connecting requires the 6-digit code shown on the screen. After repeated wrong codes, the app temporarily stops accepting connections.
    • The app does not listen on anything other than Wi-Fi (such as cellular).
    • Closing the screen stops accepting connections and deletes any partially received files. It also stops automatically after 30 minutes without activity.
    • At this point iOS asks for permission to use the "Local Network". If you do not allow it, only this feature is unavailable.
    • The app only receives game files; it does not send the user's information to the PC or anywhere else.

Games that you import may themselves access the internet (the component that runs games does not block their network access). Such communication is determined by the game's creator. PushPocket does not collect or send the data handled by that communication.

3. Information stored on the device

The following information is stored only on the user's device, and the app does not send it anywhere.

  • Imported game files and save data
  • Library information (game names, detection results, age ratings assigned by the user, etc.)
  • Settings (display, controls, per-game button layouts, etc.) and the birth year entered for age confirmation
  • Records for troubleshooting: diagnostic logs, crash records, and per-game compatibility records

All of this is removed from the device when the app is deleted.

4. When the user exports data

The following two items leave the device only when the user performs the action and chooses where to share them. The app never sends them automatically.

  • "ログを書き出す" (Export Logs; 設定 > 診断ログ / Settings > Diagnostic Logs): a copy of the diagnostic logs, crash records, and measurement reports (if any).
  • "互換性レポートを共有" (Share Compatibility Report; game detail screen): the game's folder name, the detection result, that game's compatibility records, the app version, and the device model and OS version. It does not include the device name. It does not include the game files themselves.

5. Children's privacy

The app asks for the birth year for age confirmation, but the value is stored only on the device and is not transmitted.
