Ren'Py LGPL components: corresponding source

PushPocket runs Ren'Py games with an embedded Ren'Py 8.5.3.26051504 runtime (renpy commit 39895c1e017f0b36ffea2447d97eccd69d76ee1c, renpy-build commit 7bfab40c1174f622f644b24669afd5fb167fbb79). The LGPL parts of that runtime are not linked into the app binary. They are shipped as one separate dynamic framework, PushPocket.app/Frameworks/RenPyLGPL.framework, which you can rebuild and replace.

This page provides the exact source files used to build that framework, our build scripts, and the instructions to relink. These files will stay available here for at least three years after the last distribution of the app version that uses them. Every file below is checked against the sha256 listed (the same values as in inputs.lock).

3. Rebuild

The scripts expect this layout (the work folder name is free):

work/
  tools/renpy/build-lgpl.sh
  tools/renpy/check-lgpl.sh
  tools/renpy/inputs.lock
  tools/renpy/required-exports.txt
  build/renpy-lgpl/cache/   (optional: the files of section 1; otherwise they are downloaded and checked)
chmod +x work/tools/renpy/*.sh
work/tools/renpy/build-lgpl.sh --force

The result is work/third_party/renpy-ios/RenPyLGPL.xcframework (iphoneos arm64 and iphonesimulator arm64, minimum iOS 14.0). To use modified source, put your file in the cache folder under the same name and change its sha256 in inputs.lock. If you build in another way, the framework is still a valid replacement when it has the install name @rpath/RenPyLGPL.framework/RenPyLGPL, is arm64, exports every function in required-exports.txt, and takes its SDL functions from @rpath/SDL2.framework/SDL2. check-lgpl.sh verifies this.

4. Replace the framework in the app and re-sign

  1. Unpack your PushPocket .ipa (it is a zip): unzip PushPocket.ipa.
  2. Replace Payload/PushPocket.app/Frameworks/RenPyLGPL.framework with ios-arm64/RenPyLGPL.framework from the xcframework you built.
  3. Replace Payload/PushPocket.app/embedded.mobileprovision with your own provisioning profile, then re-sign with your own Apple development certificate: 
    codesign -f -s "<certificate name>" Payload/PushPocket.app/Frameworks/RenPyLGPL.framework
codesign -f -s "<certificate name>" --entitlements <entitlements.plist> Payload/PushPocket.app
  4. Pack it again: zip -r PushPocket-relinked.ipa Payload.
  5. Install it on your own device with Xcode (Devices and Simulators) or xcrun devicectl device install app.

Ren'Py の LGPL 部分のソース

PushPocket は Ren'Py のゲームを、アプリに組み込んだ Ren'Py 8.5.3.26051504 で動かします。 そのうち LGPL の部分はアプリ本体にリンクせず、別の動的フレームワーク PushPocket.app/Frameworks/RenPyLGPL.framework として同梱しており、作り直して差し替えることができます。

このページでは、そのフレームワークを作るのに使った正確なソース、私たちのビルドスクリプト、差し替えの手順を提供します。 これらのファイルは、それを使ったアプリの版を最後に配布してから少なくとも 3 年間、ここで提供します。 各ファイルの sha256 は上の英語の表と inputs.lock に記載しています。

ファイル

  • FFmpeg 4.3.1（LGPL-2.1-or-later）：ffmpeg-4.3.1.tar.gz、Ren'Py のパッチ ffmpeg-4.3.1-sse.diff、ffmpeg-4.3.1-ff_seek_frame_binary.diff
  • GNU FriBidi 1.0.7（LGPL-2.1-or-later）：fribidi-1.0.7.tar.bz2
  • alphablit.c と surface.h（LGPL-2.0-or-later）：renpy-alphablit.c、renpy-surface.h
  • SDL_gfx（LGPL、版の記載なし）：renpy-SDL_gfxPrimitives.c、renpy-SDL_gfxPrimitives.h、renpy-SDL_gfxPrimitives_font.h
  • LGPL 以外で同じフレームワークに入るもの：libaom 3.5.0（BSD-2-Clause と AOM 特許ライセンス）libaom-3.5.0.tar.gz。コンパイル用の見出しのみ：SDL2 2.0.20（Zlib）SDL2-2.0.20.tar.gz
  • ビルドスクリプト：build-lgpl.sh、check-lgpl.sh、inputs.lock、required-exports.txt
  • ライセンス本文：LICENSE.txt

作り直しと差し替え

  1. 上の 3 章の配置にスクリプトを置き、tools/renpy/build-lgpl.sh --force を実行します。変更したソースを使うときは、キャッシュに同じ名前で置き、inputs.lock の sha256 を書き換えます。
  2. .ipa を unzip で展開し、Payload/PushPocket.app/Frameworks/RenPyLGPL.framework を、作った xcframework の ios-arm64/RenPyLGPL.framework で置き換えます。
  3. embedded.mobileprovision を自分のプロファイルに置き換え、自分の証明書で codesign により再署名します（コマンドは上の 4 章）。
  4. zip -r で .ipa に戻し、Xcode または xcrun devicectl device install app で自分の端末に入れます。
